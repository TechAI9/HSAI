HSLegendArriver 安装框架图

Windows · Python 3.12 64 位 · 分辨率 1920×1080 · 缩放 100% · 炉石全屏 · 管理员权限启动

内容整理自项目 README（github.com/magicstrangelzb/HearthstoneLegendArriver），Python 版本信息已与 python.org / PEP 693 核对。全程约 30~50 分钟，其中装依赖占大头。

四条硬约束（违反任何一条都会失败）

Python 必须是 3.12 64 位3.13 / 3.14 没有对应轮子，会卡在换牌、AI 识别全废
项目路径不能有中文统一用 D:\HS，含中文或空格必出问题
1920×1080 / 缩放 100%点击坐标是硬编码的，缩放不是 100% 会整体错位
炉石用「全屏」不用「最大化」最大化会让窗口客户区偏移，法术指定目标持续失败

1

下载项目

约 3 分钟

目标：在磁盘上得到一个纯粹英文路径的项目文件夹 D:\HS

1.1打开项目主页
浏览器地址栏输入 github.com/magicstrangelzb/HearthstoneLegendArriver → 回车
成功：看到带 README 的项目主页，右上角有 Star 数
失败：页面打不开 → 换个浏览器，或稍后重试（国内访问 GitHub 偶尔不稳）
1.2下载源码压缩包
点右侧绿色按钮 <> Code → 下拉菜单最下面点 Download ZIP
成功：浏览器开始下载 HearthstoneLegendArriver-main.zip
失败：找不到绿色按钮 → 页面没加载完，按 F5 刷新
1.3找到刚下载的文件
按 Win + E 打开文件资源管理器 → 左侧点「下载」
成功：列表里能看到那个 zip 文件
1.4解压到 D 盘根目录
右键 zip → 全部解压缩… → 目标框内容改成 D:\ → 点「提取」
成功：D 盘根目录出现文件夹 HearthstoneLegendArriver-main
失败：提示路径太长 → 换成用 7-Zip 解压
1.5重命名成纯英文短路径
右键该文件夹 → 重命名 → 改成 HS → 回车
成功：最终路径就是 D:\HS，进去能看到 requirements.txt、web_ui.py
注意：千万不要放在桌面或「文档」这类中文路径下
2

安装 Python 3.12

约 5 分钟

目标：让终端里的 python --version 输出 Python 3.12.x

2.1打开 3.12 的下载页
浏览器打开 python.org/downloads/release/python-31210/
说明：3.12.10 是 3.12 系列最后一个提供 Windows 安装包的版本，再往后的 3.12.11~3.12.14 只有源码，没有 exe
2.2下载 64 位安装包
页面拉到最底部 Files 表格 → 点 Windows installer (64-bit)（约 25.7 MB）
成功：下到 python-3.12.10-amd64.exe
失败：只看到 Source release 或 embeddable → 你进错版本页了，回到 2.1 的链接
2.3关键一步：勾上 PATH 再装
双击 exe → 第一屏最下面勾选 Add python.exe to PATH → 点 Install Now → 装完点 Close
成功：界面显示 Setup was successful
失败：忘了勾 → 卸载重装，别手工去配环境变量（最容易配错）
2.4验证版本
按 Win + R → 输入 cmd → 回车 → 输入 python --version → 回车
成功：显示 Python 3.12.10，继续下一步
失败：显示 3.14.x / 3.13.x，或提示「不是内部或外部命令」→ 先停下来，说明电脑里已有别的 Python 抢了位置，把结果告诉我
3

安装依赖

10~30 分钟

目标：把 PaddleOCR 等一大堆库装进 Python，这步最慢，中途不要关窗口

3.1进项目文件夹
按 Win + E → 地址栏输入 D:\HS → 回车 → 确认能看到 requirements.txt
3.2在这里就地打开终端
点窗口顶部地址栏（显示 D:\HS 的那一条）→ 全选删掉 → 输入 powershell → 回车
成功：弹出终端窗口，提示符是 PS D:\HS>
失败：提示符不是 D:\HS → 关掉，按 3.1 重新来一遍
3.3粘贴安装命令并回车
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
注意：在终端里用鼠标右键粘贴，Ctrl+V 有时候没反应
失败：报 pip: 无法将&quot;pip&quot;项识别为... → 把命令开头的 pip 换成 python -m pip 再试
3.4等待 10~30 分钟
屏幕会滚动大量下载进度，不要关窗口、不要按 Ctrl+C
成功：重新出现 PS D:\HS> 提示符，且上方没有大片红色报错
失败：中间有红色下载失败 → 原样重跑同一条命令，已下好的会自动跳过
4

系统与炉石设置

约 3 分钟

目标：让屏幕和游戏画面与脚本里硬编码的坐标完全对齐

4.1改分辨率
按 Win + I → 系统 → 屏幕 → 显示器分辨率选 1920 × 1080
4.2改缩放
同一页往下找到「缩放」→ 选 100%
注意：缩放 125% / 150% 会让所有点击整体偏移，这是最常见的「看着在跑但什么都没做」
4.3炉石改成全屏
打开炉石传说 → 设置 → 选项 → 显示 → 显示模式 = 全屏
禁止：不要用「最大化窗口」。窗口化时随从还能吸附成功，但法术指定目标会一直失败
4.4摆好炉石盒子
打开炉石盒子（必须简体中文）→ 把左侧「推荐打法 / 打法参考A」面板留在屏幕左侧
注意：面板位置要完整可见，后面阶段 5 还要用校准工具微调
4.5清场
关掉可能遮挡炉石或盒子的悬浮窗、聊天软件、录屏工具
5

启动与自检

约 5 分钟

目标：网页控制台打开且环境自检全绿，然后完成校准开始对战

5.1开管理员终端
按 Win + X → 松开 → 按 A → 弹窗点「是」
必须管理员：否则鼠标键盘点击会被系统拦掉，现象就是「脚本在跑但点了没反应」
5.2进入项目目录
输入 cd D:\HS → 回车
失败：提示符没变化或报错 → 先输入 D: 回车，再输入 cd HS 回车
5.3启动脚本
输入 python web_ui.py → 回车
成功：终端打印本地地址，浏览器自动打开 http://127.0.0.1:8765
失败：提示 python 不是命令 → 回到阶段 2；提示缺模块 → 回到阶段 3
5.4看环境自检
网页顶部「🧪 环境自检」卡片，逐项确认：Python 3.12 64 位、依赖齐全、管理员权限、分辨率/缩放、日志目录
失败：只要有 ❌ 就别往下走，卡片里会直接给出修复命令
5.5填基础配置
「👤 基础配置」里填 用户 ID = 当前战网昵称完整含 #编号；再填炉石日志目录
失败：换过账号没改这里 → 整局都会被判成「对手回合」，一张牌都不出，日志里还不报错
5.6先「开始运行」再校准
点「🪄 开始运行」（只弹浮窗，不会开打）→ 浮窗点「校准」→ 把绿框对准盒子「打法参考A」面板 → 顶部提示条变绿
成功：提示条显示「已检测到盒子面板」，按 Esc 收起
5.7开始对战
点「⚔️ 开始对战」→ 二次确认 → 脚本开始跑
急停：任何时候按 Ctrl + Q 立即停止

快捷键总表

按键作用用在哪一步
Win + E打开文件资源管理器1.3 / 3.1
Win + R打开运行框（用来验证 Python 版本）2.4
Win + I打开系统设置（改分辨率、缩放）4.1 / 4.2
Win + X → A打开管理员终端（松手后再按 A）5.1
Ctrl + A / Ctrl + X全选 / 剪切1.4 / 1.5
F5刷新网页1.2
Ctrl + Q脚本运行中立即停止5.7

故障对照表

看到的现象真正原因怎么修
提示「不是内部或外部命令」装 Python 时漏勾 Add to PATH卸载 Python 3.12 重装，勾上那一项
自检显示 Python 版本 ❌电脑里有 3.13 / 3.14 抢了 python 这个名字卸载其他版本，或改 PATH 顺序后重开终端
脚本在跑但一张牌都不出用户 ID 不完整，或炉石用了最大化窗口补全 #编号；炉石改全屏
点下去完全没反应没用管理员权限启动用 Win + X → A 重新启动
法术一直打不出去分辨率/缩放不对，坐标整体偏移改回 1920×1080 + 100%
启动就报错、闪退路径里含中文或空格把项目挪到 D:\HS
卡在换牌、AI 识别全废Python 版本不是 3.12按阶段 2 重装 3.12
盒子意见读不到校准框没对准「打法参考A」面板浮窗点「校准」，提示条变绿才算好

启动前最终检查清单

  • 项目路径是 D:\HS，纯英文、无空格、无中文
  • python --version 输出 3.12.x（64 位）
  • 依赖安装命令已跑完，终端没有红色报错
  • 桌面分辨率 1920×1080，缩放 100%
  • 炉石显示模式 = 全屏（不是最大化窗口）
  • 炉石盒子为简体中文，左侧「推荐打法」完整显示
  • 「用户 ID」填的是当前账号完整战网昵称（含 #编号）
  • 网页「🧪 环境自检」里没有 ❌
  • 浮窗「校准」提示条显示「已检测到盒子面板」
  • 脚本用管理员权限启动
  • 「🩺 存活检测」保持开启（防炉石闪退后空转）
